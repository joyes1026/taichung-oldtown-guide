# 舊城慢慢逛

以 Google 地圖「台中舊城特色店家」共用清單為基礎的介紹式網站，保留全部 40 個地點。

[開啟已發佈網站](https://taichung-oldtown-finds.joye1026a.chatgpt.site)（私人網站，需獲授權的 ChatGPT 帳號登入）

## 功能

- 六種店家分類、關鍵字搜尋與八種視覺色系篩選，可交叉使用。
- 展開店名可閱讀介紹、色系判讀說明與 Google 地圖來源連結。
- 依地圖主要照片中的 LOGO、清楚可辨識的店名招牌與園區題字整理色票。26 個地點可辨識，14 個列為未確認；色票是視覺近似，並非官方標準色。
- 奶油底色、暖棕文字與陶土色操作按鈕；支援桌面及手機。

## 本機使用

此專案使用 HTML、CSS 與 JavaScript，不需安裝第三方套件。直接開啟 `dist/index.html` 即可瀏覽。

若已安裝 Node.js，也可以啟動本機預覽：

```sh
npm start
```

開啟 `http://127.0.0.1:4174`。`/mobile` 提供 390px 寬的手機排版檢查畫面。

執行功能檢查：

```sh
npm test
```

檢查涵蓋 40 筆不重複資料、色系資料完整性、分類／顏色／搜尋組合、無結果狀態與清除條件。

## 檔案

- `dist/index.html`：可直接部署的完整網站，店家與色系資料也在此檔案。
- `preview.cjs`：僅限本機的靜態預覽。
- `check.cjs`：功能檢查。
- `DESIGN.md`：介面與配色紀錄。
- `.openai/hosting.json`：既有 Sites 網站的部署設定。

## 資料來源與範圍

[Google 地圖原始共用清單](https://www.google.com/maps/@/data=!3m1!4b1!4m3!11m2!2sVd7ig9h---hcdT1eMSh8CEVYr7FQqQ!3e3)由舊城有點編分享，原清單由活動夥伴珮慈製作，供「我在舊城開了一間＿＿＿店」活動創作參考。資料與色系觀察整理於 2026-10-22。

分類和短介依店名及地圖類型編輯整理；不代表店家官方說明。清單中的檜意森活村位於嘉義，網頁另有標示。營業時間、地址、照片與最新動態應以店家及 Google 地圖為準。網站未轉載店家照片或 LOGO 圖檔；字體透過 Google Fonts 載入。
